# Analysis Quickstart

Run in a CMSSW environment with PyROOT available.

```bash
python3 analysis/plot_basic.py --input "path/to/ntuple.root" --outdir analysis/plots
```

Outputs:

- `trigger_efficiency.png`
- `top_mass_proxy.png`
- `lepton_pt.png`
- `jet_pt.png`
- `jet_flavour.png`
- `jet_charge_score.png`
- `debug_njets.png`
- `debug_nlep.png`
- `basic_plots.root`
